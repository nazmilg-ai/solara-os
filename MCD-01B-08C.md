## Documentation Conventions: Advisor Selection / Derived Default / Supplier Capability

Consistent with every other product specification in this project, the following three terms are used throughout this document as **documentation conventions only** — they are not new architectural layers and do not modify MCD-01A §3:

- **Advisor Selection** — a value the advisor actively chooses. Architecturally, this is the Configuration layer (or, where the choice changes construction, the Construction/System layer).
- **Derived Default** — a value the system determines automatically from an Advisor Selection, without a separate question. Architecturally, this is the Accessory Engine and/or Supplier Capability Engine resolving a compatible component or value from an existing Configuration selection.
- **Supplier Capability** — the actual data (dimensions, weights, compatibility, pricing, availability) that makes a Derived Default resolvable. Architecturally, this is the Supplier Capability Engine (MCD-01A §5.9) and the Supplier Capability Library, maintained in MCD-04.

## 4. Construction Classification

Applying MCD-01A §3's three-test model to this construction's own open questions (the Construction Group itself is already settled by MCD-01B-08 §2 and is not re-tested here):

**4.1 Cassette (MCD-01B-01 §3) does not apply within this Construction Group.** Test 1: does a Cassette-equivalent split exist? No evidence shows an open/enclosed sub-split within the Full-Frame Bead-Mounted System — the surrounding aluminium frame is itself the sole enclosing structure for every evidenced configuration of this product; there is no second, cassette-style enclosure option sitting inside or instead of the frame. Base Roller's Standard/Cassette Construction Variant split (MCD-01B-01 §3) is therefore not inherited into this document — it is superseded by the single Full-Frame Bead-Mounted System Construction Group already established at family level, not re-created as a second variant axis here.

**4.2 Control System (chain-operated vs. tensioned-spring) is Configuration, not a further Construction Variant.** Test 1: does selecting chain vs. tensioned-spring change this construction's manufacturing/assembly route (frame, tube, bracket, corner-cap, fixing convention)? The evidence shows frame colours, corner-cap/bracket colour mapping (§9.1–§9.2), tube diameter (§7.1), and side-frame fixing-hole/fixing-bracket-quantity convention (§5.4) apply identically regardless of which control system is selected — only the bottom-bar/operating mechanism and control-side field differ (tensioned-spring uses a wrap-around bottom bar and a control handle; chain uses a standard bottom bar and a looped chain). This is the same shape of difference base Roller's own Bracket Type and Control Side were tested against and found to be Configuration (MCD-01B-01 §3/§11) — a mandatory selection for correct operation that does not change the surrounding frame construction. Test 1 fails; Test 2 passes (a control system must be selected for the blind to be installed/operated correctly). **Conclusion: Configuration.**

## 5. Full-Frame Bead-Mounted System — Shared Construction-Group Content Established by This Document

This section states the technical content that is genuinely shared across the whole Full-Frame Bead-Mounted System Construction Group (not specific to Roller), confirmed by this construction's own evidence and proposed as the shared reference other future variants in this Construction Group should cite rather than duplicate (§2). MCD-01B-08 itself deliberately left these as schema-only, unpopulated family principles (§6: "do not create one universal colour list... will always be filtered by the exact variant/supplier product once populated"); this section is where that population is first proposed, using this construction's own confirmed evidence.

**5.1 Measurement basis.** Glass size (glass width, glass drop) is the confirmed measurement basis for this construction. Do not use Recess or Exact measurement for this construction — no evidence supports either being required here. Whether any other Full-Frame Bead-Mounted sibling requires Recess/Exact instead (as MCD-01B-08 §6 anticipates some supplier systems might) is that sibling's own open question, not resolved or assumed by this document.

**5.2 Frame colour.** Frame colour is a mandatory Configuration-layer field, selected after supplier/route and product, and must remain distinct from fabric, slat, bottom-bar, corner-cap, bracket, and control-handle colour fields — these may not share the same name for the same visible component set (e.g. one frame colour may pair with a differently-named corner-cap colour and a differently-named bracket colour; §9.2 gives this construction's own confirmed mapping). Frame, corner-cap, and bracket colour mappings must be stored as separate, explicit fields rather than assumed to match the frame colour name.

**5.3 Handle clearance and packers.** Handle packers of **2 mm and 6 mm only** are confirmed. An earlier reference to a 3 mm packer size is explicitly withdrawn — it is not carried into this document as a valid size. Packers are used where a turning window handle rubs, slides against, or contacts the frame, and installation must confirm: the handle remains securely fixed; the locking mechanism operates correctly; the window opens/closes correctly; the handle clears the frame through its full range of movement; the packer does not itself create a new obstruction.

**5.4 Fixing brackets, clips and bead depth.** Bracket/clip size is selected from supplier/route-supported values only — not every product or route supports every size. **Route 1's evidence confirms 9 specific sizes: 18, 20, 22, 24, 26, 28, 30, 32, and 38 mm**, each with a real product code per size/colour combination (exact codes are supplier-specific identifiers and belong in MCD-04, not this document). **Route 2's own bracket sizes are not separately confirmed** — this document does not assume Route 2 supports the same 9 sizes merely because Route 1 does, per MCD-01B-08 §7's no-cross-route-inheritance principle; this is logged in Open Evidence Items (§14).

**Fixing-hole convention (side frames):** two holes are punched into the side frames as standard, with a third hole added over **1,100 mm drop** — confirmed by this construction's own evidence. **Carried forward, not resolved here:** the working-evidence review that preceded this document found this same 1,100 mm-drop trigger confirmed identically across every evidenced Full-Frame Bead-Mounted product examined so far except one — a single evidenced product's specification instead states the third hole is triggered by 1,100 mm **width**, not drop, for what is otherwise the same nominal convention. That discrepancy sits entirely within a sibling product not drafted in this document (Aluminium Venetian) and is not resolved here; it is logged in this document's Open Evidence Items (§14) purely so the flag is not lost when that sibling is eventually drafted, and is not treated as settled either way by this document's own drop-trigger confirmation.

**Fixing bracket quantity by drop:** 4 brackets under 1,100 mm drop, 6 brackets from 1,101 mm drop upward — confirmed by this construction's own evidence.

## 7. Validation Rules

The shared Validation Engine performs validation. This construction's evidence provides two independently evidenced routes; per MCD-01B-08 §7's no-cross-supplier/no-cross-route-inheritance principle, neither route's figures are applied to the other.

**7.1 Route 1 (a Finished-Blind Manufacturer providing a confirmed technical specification for this construction):**
- Chain-operated: glass width 200–1,400 mm.
- Tensioned-spring-operated: glass width 330–1,400 mm.
- Glass drop: 300–1,800 mm, with the actual achievable maximum fabric-dependent (matching the same fabric-limits-vs-system-limits caution base Roller's own §7 already establishes for fabric railroading/joining — the lowest applicable limit governs).
- Square-frame guidance: a 5 mm deduction from width and drop is this route's own stated guidance, not a universal Full-Frame Bead-Mounted rule.
- Tube: 25 mm aluminium.

**7.2 Route 2 (a second Finished-Blind Manufacturer, manufacturing this construction in-house):**
- Confirmed: chain operation available left or right, on both of this route's two frame-colour tiers (§10).
- Confirmed: not every fabric can be made to this route's maximum drop — thicker fabric yields a smaller achievable maximum drop, the same fabric-dependent-limit pattern as Route 1.
- **Not separately confirmed:** a true technical minimum/maximum width or drop for this route. The only width figures on file are a pricing-grid range (approximately 610–1,400 mm), and per MCD-01B-08 §7's explicit field-separation principle, a pricing-grid's first/last entries are not automatically technical limits — this is recorded as a **Priced Band**, not a Technical Minimum/Maximum, and must not be presented to an advisor as a confirmed manufacturing limit until independently confirmed.
- Tensioned-spring operation is not confirmed one way or the other for this route (absent from the evidence, not excluded by it).

**7.3 No universal Full-Frame Bead-Mounted Roller limit should be created from either route's values — each stays route-specific**, consistent with MCD-01B-08 §7's own standing principle.

## 13. Child Safety

The shared Child Safety Engine implements BS EN 13120 compliance (MCD-01A §5.6). This construction's own implementation:

- **Tensioned-spring control** is handle-operated (via the wrap-around bottom bar's control handle, §7.1) with no accessible chain or cord evidenced — provisionally consistent with MCD-01B-08 §9's own stated pattern that handle-operated tensioned systems "may be Safe by Design where evidence confirms this." This is recorded as a provisional classification pending explicit confirmation, not asserted as settled.
- **Chain control** requires a chain safety device. **No specific device is yet evidenced for this construction.** This must not be assumed to be the same device named in any sibling product's own evidence (e.g. a chain-tidy device evidenced for a different Full-Frame Bead-Mounted sibling) — per MCD-01B-08 §7's no-cross-inheritance principle applied here to cross-product inheritance within the same Construction Group, not only cross-supplier inheritance. Recorded as Supplier Confirmation Required.
- Chain length remains a Child Safety Engine calculation derived from drop (MCD-01B-01 §12's own established principle) — not an advisor Configuration input, and not restated as a formula here since none is evidenced for this construction specifically.

## 15. Blocking Rules
